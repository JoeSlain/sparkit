# Sparkit promo video (Remotion)

Composition `SparkitPromo` (~34s, 1920×1080): kinetic English pitch with real tool icons (Simple Icons + custom marks for Tamagui, Lingui, Maestro, Playwright, Stim).

Scenes: intro rain → native/web devices → stack orbit → verify terminal → Lingui flip → DX constellation → outro.

```sh
pnpm --filter @sparkit/video studio
pnpm --filter @sparkit/video render
```

Studio: http://localhost:3000 (or `pnpm dev:video`)  
Output: `apps/video/out/sparkit-promo.mp4`
